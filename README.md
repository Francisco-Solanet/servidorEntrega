# TP1 – Servidor de Vehículos

## Descripción

Primera entrega del proyecto Servidor de Vehículos, desarrollado en Go. Esta versión implementa la estructura inicial de la aplicación y permite ejecutar el servidor desde la terminal.

## Tecnologías utilizadas

- **Go:** lenguaje de programación utilizado para desarrollar la aplicación.

## Requisitos

Para ejecutar el proyecto se necesita tener instalado Go.

## Ejecución

Clonar el repositorio y entrar en la carpeta del proyecto:

```bash
git clone https://github.com/francisco2015solane-web/servidorEntrega.git
cd servidorEntrega
```

Luego, ejecutar la aplicación con:

```bash
go run .
```

## Objetivo de la entrega

Esta primera entrega establece la base inicial del proyecto, sobre la cual se incorporan nuevas funcionalidades y mejoras en las siguientes etapas.
